# Interview Prep

Question-and-answer banks for project-discussion interview rounds.

## Projects

| Project | Question bank | What it covers |
|---|---|---|
| **Midas** — Spring Boot + Kafka + JPA transaction processor (JPMorganChase Forage simulation) | [midas-questions.md](midas-questions.md) | ~360 questions with answers: architecture, tech choices, database, API design, security, Spring/JPA/Kafka internals, concurrency, failures, scaling, testing, redesign, Blinkit-scale scenarios, live coding, CS fundamentals, line-by-line code questions, plus personal-story answers |

## How to use the Midas bank

1. Start with **⭐ Top 25 most likely questions** at the top of [midas-questions.md](midas-questions.md).
2. Fill in the ✏️ parts of **Your story — drafted personal answers** (P.1–P.6) at the end of the file.
3. Then go deeper by category (1–17), and finish with the **Gap-check additions** (GC.1–GC.120).
4. Answers marked **[Confirm: …]** still need checking against the real project before you rely on them.
